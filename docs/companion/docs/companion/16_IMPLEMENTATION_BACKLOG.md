## 每一份 PR 或交付報告
1. 目標與完成範圍；2. 修改檔案與理由；3. 自動化及實機測試記錄；4. 性能/雲端費用；5. 還沒完成的項目；6. 如何回退；7. 明確聲明無新 eFuse 寫入/格式化；8. 是否需要使用者動手操作硬體。
