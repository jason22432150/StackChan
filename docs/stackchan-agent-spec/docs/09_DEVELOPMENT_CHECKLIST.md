- 2026-11-18 使用者明確限制：整個專案禁止直接或間接燒寫 eFuse；一般韌體燒錄批准不構成例外。建置、工具及首次開機路徑均須核對，詳見 `05_SECURITY_PRIVACY.md §1`。保留預設 NVS 既有格式，通知短效憑證留在 RAM。

- 不自行改變已定義 Fail-Closed、單使用者、無 Agent 遠端控制、無 CoreS3 通知歷史等底線。
